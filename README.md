# Personal Portfolio

My personal developer portfolio showcasing my projects, skills and education.

🔗 [View Portfolio URL]

## Tech Stack

- React
- Tailwind CSS
- JavaScript
- Vite
- Git and GitHub

## Features

- Responsive layouts for desktop, tablet and mobile
- About section with a scroll-triggered 3D photo flip
- Downloadable resume
- Project cards with live demo and source code links
- Education timeline and technical skills section
- Mobile navigation
- Dark theme with violet accents

## Run Locally

Clone the repository:

```bash
git clone https://github.com/nyx-Anna/Anjali-Portfolio.git
cd Anjali-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

Preview the build locally:

```bash
npm run preview
```
